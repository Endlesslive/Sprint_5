# Sprint_5 - Автоматизация тестирования Stellar Burgers

Проект автоматизации тестирования веб-приложения Stellar Burgers с использованием Selenium WebDriver и pytest.

## Описание

Stellar Burgers - это космический фастфуд-сервис для создания и заказа бургеров из необычных ингредиентов.

## Требования

- Python 3.8+
- Google Chrome
- pip
